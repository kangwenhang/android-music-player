# 科帕奇音乐播放器

专为 **安卓 4.2.2(API 17)** 车机设计的音乐播放器(科帕奇 2015 款改装车机,7 寸 1024×600 横屏)。

## 功能特性

### 播放核心
- 本地音乐扫描与播放(MediaStore + MediaPlayer)
- **Navidrome 服务器对接**(Subsonic API,支持网络流式播放)
- 本地/网络音乐来源一键切换
- **开机自动播放**(可开关,记忆上次播放歌曲和进度,断点续播)
- 播放模式:顺序 / 单曲循环 / 随机
- 后台播放 + 通知栏控制
- 方向盘媒体按键响应

### 搜索
- 实时搜索(本地即时过滤,网络防抖搜索)
- 按歌曲名和歌手名匹配,精准过滤

### 均衡器
- 系统 Equalizer,5 段频段调节
- **内置预设**:关闭、流行、摇滚、爵士、古典、重低音
- **自定义预设**:保存/删除个人调节方案
- **单曲 EQ 绑定**:为每首歌绑定独立均衡器设置,切歌自动恢复
- 底部控制栏 EQ 快捷按钮,实时显示当前模式

### 界面与歌词
- **歌词叠加在封面上**(封面放大模糊作为底色背景,歌词在上)
- 加大歌词字体,当前行 28px / 其他行 22px
- 禁用列表切换动画,减少视觉跳动感
- 粉橙渐变 APP 图标,圆角矩形设计

### 车机适配优化
- **电阻屏优化**:大按钮(64/80dp)+ 大间距 + 大字体,便于触控
- **U 盘音乐性能优化**:无封面缓存 + 滚动停止预加载,消除滑动卡顿
- **启动优化**:延迟重型初始化,避免白屏
- **网络歌曲缓存优先加载**:切换网络模式秒开,后台静默更新
- 全屏沉浸模式:隐藏状态栏和虚拟导航键
- 横屏锁定,适配 1024×600 分辨率
- 设置中显示屏幕分辨率与 DPI 检测

### 其他
- Navidrome 服务器设置界面(地址/用户名/密码)
- 服务器状态实时监控(断线 30 秒自动重连)
- 关于页面,支持检测 GitHub 正式版更新

## 技术栈

- 原生 Java
- AndroidX appcompat 1.3.1 / recyclerview 1.2.1
- AGP 7.4.2 + Gradle 7.5
- minSdk 17 / targetSdk 28 / compileSdk 30
- APK 仅 v1 签名 + zipalign 4 字节对齐(安卓 4.2.2 兼容)

## 编译

用 Android Studio 打开本目录,同步后即可编译运行。确保已安装 Android SDK Platform 30 和 Build Tools 30.0.3。

或通过 GitHub Actions 自动构建(push 到 main 或 local-test 分支触发),自动生成 APK 并发布 Release。

## Navidrome 配置

1. 打开 App,点击右上角"设置"按钮
2. 选择"服务器设置"
3. 输入服务器地址(如 `http://192.168.1.100:4533`)、用户名和密码
4. 点击"测试连接"验证,然后"保存"
5. 点击顶栏"本地/网络"按钮切换到网络来源即可浏览播放
