# 科帕奇音乐播放器

专为 **安卓 4.2.2(API 17)** 车机设计的音乐播放器(科帕奇 2015 款改装车机,7 寸 1024×600 横屏)。

## 功能特性

### 播放核心
- 本地音乐扫描与播放(MediaStore + MediaPlayer)
- **Navidrome 服务器同步**(Subsonic API,同步服务器歌曲列表到本地)
- 播放模式记忆:顺序 / 单曲循环 / 随机,状态自动保存
- **开机自动播放**(可开关,记忆上次播放歌曲和进度,断点续播)
- 播放模式:顺序 / 单曲循环 / 随机
- 后台播放 + 通知栏控制
- 方向盘媒体按键响应

### 搜索
- 实时搜索(本地即时过滤,网络防抖搜索)
- 按歌曲名和歌手名匹配,精准过滤

### 均衡器
- 系统 Equalizer,5 段频段调节
- **内置预设**:关闭、流行、摇滚、爵士、古典、重低音
- **自定义预设**:保存/删除个人调节方案
- **单曲 EQ 绑定**:为每首歌绑定独立均衡器设置,切歌自动恢复
- 底部控制栏 EQ 快捷按钮,实时显示当前模式

### 界面与歌词
- **歌词叠加在封面上**(封面放大模糊作为底色背景,歌词在上)
- 加大歌词字体,当前行 28px / 其他行 22px
- **VBR 歌词同步**:混合位置追踪(系统时钟+MediaPlayer),自动校正 VBR MP3 位置偏差
- **歌词偏移手动调整**:长按歌词区逐 200ms 微调,设置自动保存,每首歌独立
- 禁用列表切换动画,减少视觉跳动感
- 粉橙渐变 APP 图标,圆角矩形设计

### 车机适配优化
- **电阻屏优化**:大按钮(64/80dp)+ 大间距 + 大字体,便于触控
- **本地列表缓存秒开**:歌曲列表持久化到本机,打开即显示,不读 U 盘
- **点击歌曲才读 U 盘**:列表从缓存加载,仅播放时才访问 U 盘文件
- **手动刷新列表**:设置中新增"刷新歌曲列表",U 盘增删歌曲后手动更新
- **三级封面缓存**:内存 LruCache(28MB,5000+张)→ 内部存储磁盘缓存(200MB)→ U 盘/网络
- **不滚动时全量载入内存**:停止滑动后后台把磁盘缓存全部载入内存,之后滚动零磁盘 IO
- **滚动性能深度优化**:滑动时暂停磁盘 IO 和歌词更新,停止后补加载,消除卡顿
- **播放状态同步**:从桌面返回时自动同步当前播放歌曲,解决自动切歌后显示不同步
- **收藏/搜索高亮**:过滤后只高亮当前播放歌曲,不在列表中则清除高亮
- **导航播报自动压低音量**:AudioFocus 支持,导航播报时音乐自动降低音量,播报结束恢复
- **应用内更新**:检测新版本并下载安装,带进度条显示
- **启动优化**:延迟重型初始化,避免白屏
- **网络歌曲缓存优先加载**:切换网络模式秒开,后台静默更新
- 全屏沉浸模式:隐藏状态栏和虚拟导航键
- 横屏锁定,适配 1024×600 分辨率
- 设置中显示屏幕分辨率与 DPI 检测

### 其他
- Navidrome 服务器设置界面(地址/用户名/密码)
- 服务器状态实时监控(断线 30 秒自动重连)
- 关于页面,支持检测 GitHub 正式版更新

## 技术栈

- 原生 Java
- AndroidX appcompat 1.3.1 / recyclerview 1.2.1
- AGP 7.4.2 + Gradle 7.5
- minSdk 17 / targetSdk 28 / compileSdk 30
- APK 仅 v1 签名 + zipalign 4 字节对齐(安卓 4.2.2 兼容)

## 编译

用 Android Studio 打开本目录,同步后即可编译运行。确保已安装 Android SDK Platform 30 和 Build Tools 30.0.3。

或通过 GitHub Actions 自动构建(push 到 main 或 local-test 分支触发),自动生成 APK 并发布 Release。

## Navidrome 配置

1. 打开 App,点击右上角"设置"按钮
2. 选择"服务器设置"
3. 输入服务器地址(如 `http://192.168.1.100:4533`)、用户名和密码
4. 点击"测试连接"验证,然后"保存"
5. 点击"同步歌曲"按钮,将服务器歌曲列表同步到本地

## 版本说明

- **main 分支**:正式版,推送后自动构建并创建 GitHub Release
- **local-test 分支**:测试版,推送后自动构建并创建预发布(Pre-release)
- 版本号基于 git tag,正式版如 `v4.5`,预发布如 `v4.5.190-pre`
- CI 构建 versionCode 使用 `GITHUB_RUN_NUMBER + 100000`,跨分支单调递增,确保可覆盖安装

- **清理无用矢量图标**:移除 ic_play_sequence/ic_play_shuffle/ic_play_repeat_one 三个矢量 drawable,减少 APK 体积

### v5.0 更新内容

- **Navidrome 功能调整**:服务器对接改为仅同步歌曲列表,不再支持网络流式播放

### v4.7 更新内容

- **修复搜索关闭后高亮丢失**:清除搜索后当前播放歌曲在分批加载范围外时,高亮不再丢失,自动加载到该位置
- **修复车机歌词不同步**:安卓 4.x 老设备 MediaPlayer 对 VBR MP3 位置报告不准,新增混合位置追踪(系统时钟 + MediaPlayer),自动校正 VBR 偏差
- **歌词偏移手动调整**:长按歌词区弹出偏移调整对话框,可逐 200ms 微调个别歌曲的歌词同步,设置自动保存

### v4.6 更新内容

- **修复 SSL/TLS 无法更新**:安卓 4.x 根证书太旧不信任 GitHub,新增 TrustAllManager 跳过证书验证 + HTTP 代理优先 + 更多镜像
- **修复更新检查崩溃**:代理镜像返回 HTML 错误页时不再崩溃,自动重试其他镜像直到获得合法 JSON
- **修复首次加载卡顿**:缓存加载、排序、MediaStore 扫描全部移到后台线程,不阻塞主线程
- **修复点击歌曲无响应**:service 未绑定时记录待播放位置,绑定完成后自动播放,并提示"正在初始化"

### v4.5 更新内容

- **封面缓存支持 5000 首歌**:磁盘缓存扩至 200MB,内存缓存扩至 28MB,缩略图 1x 采样(48px),单张仅 2-5KB
- **不滚动时全量载入内存**:停止滑动后后台把磁盘缓存全部载入内存 LruCache,之后滚动列表零磁盘 IO,完全不卡
- **修复播放状态不同步**:切到桌面后自动切歌,回到 app 时同步当前播放歌曲信息(原因为 onPause 期间广播被错过)
- **修复收藏/搜索高亮错误**:过滤后用歌曲身份重新定位高亮,当前播放歌曲不在列表中时清除高亮

### v4.2 更新内容

- **修复降级安装失败**:CI 构建改用 GitHub Actions run number 作为 versionCode,解决 local-test 版本号低于 main 导致"应用未安装"的问题
- **导航播报自动压低音量**:新增 AudioFocus 支持,导航播报时音乐自动降低至 20% 音量,播报结束自动恢复
- **关闭性能日志**:正式版移除 PerfLogger 日志输出,减少 IO 开销

### v4.1 更新内容

- **封面缓存切回内部存储**:经性能日志分析,eMMC 读取比 U 盘更稳定,封面缓存从 U 盘改回内部存储
- **内存缓存扩容**:LruCache 从 4MB 扩至 12MB,减少滚动时缓存未命中导致的磁盘读取
- **滚动时跳过磁盘 IO**:cacheOnlyMode 模式下内存缓存未命中直接显示占位图,不提交磁盘读取任务
- **消除 onBindViewHolder 对象分配**:复用监听器和 Runnable,减少 GC 冻结(83-89ms → 消除)
- **LrcView 绘制优化**:StaticLayout 缓存 + 避免每帧分配,减少歌词滚动时的主线程开销
- **封面加载优化**:单次 decodeFile 替代双读,提供 inTempStorage 缓冲区减少 GC

### v3.0 更新内容

- **性能日志系统**:新增 PerfLogger 工具,Choreographer 帧率监控 + 主线程操作耗时打点,日志写入 U 盘方便分析
- **滚动时暂停歌词和进度更新**:列表滑动期间暂停 LrcView 滚动和进度条刷新,停止后恢复
- **封面预提取**:同步/扫描后后台提取所有封面到磁盘缓存,滚动时只读缓存不碰 U 盘
- **无封面黑名单持久化**:确认无封面的歌曲记录到文件,避免重启后重复读 U 盘

## 说明

ExoPlayer/Media3 最低需 API 16,虽可用于安卓 4.2.2,但为保证兼容性和稳定性,采用系统原生 MediaPlayer。
