# 科帕奇音乐播放器

适配 **安卓 4.2.2(API 17)** 车机(科帕奇 2015 款改装车机,7 寸 800×480 横屏)的音乐播放器。

## 功能

- 本地音乐扫描与播放(MediaStore + MediaPlayer)
- **Navidrome 服务器对接**(Subsonic API,支持网络流式播放)
- 本地/网络音乐来源一键切换
- **网络歌曲缓存优先加载**(切换网络模式秒开,后台静默更新)
- **搜索功能**(实时搜索,本地即时过滤,网络防抖搜索)
- **歌词叠加在封面上**(封面放大模糊作为底色背景,歌词在上)
- 播放模式:顺序 / 单曲循环 / 随机
- **播放按钮状态颜色**(播放蓝色 / 暂停红色)
- 均衡器(系统 Equalizer,5 段频段 + 预设)
- 后台播放 + 通知栏控制
- 方向盘媒体按键响应
- Navidrome 服务器设置界面(地址/用户名/密码)
- 服务器状态实时监控(断线30秒自动重连)

## 车机适配优化

- **电阻屏优化**:大按钮(64/80dp)+ 大间距 + 大字体,便于触控
- **低性能优化**:网络歌曲分批加载(50首/批)+ 缓存优先,避免卡顿
- **全屏沉浸模式**:隐藏状态栏和虚拟导航键
- 横屏锁定,适配 800×480 分辨率

## 技术栈

- 原生 Java
- AndroidX appcompat 1.3.1 / recyclerview 1.2.1
- AGP 7.4.2 + Gradle 7.5
- minSdk 17 / targetSdk 28 / compileSdk 30

## 编译

用 Android Studio 打开本目录,同步后即可编译运行。确保已安装 Android SDK Platform 30。

或通过 GitHub Actions 手动触发构建(workflow_dispatch),自动生成 APK 并发布 Release。

## Navidrome 配置

1. 打开 App,点击右上角"设置"按钮
2. 选择"服务器设置"
3. 输入服务器地址(如 `http://192.168.1.100:4533`)、用户名和密码
4. 点击"测试连接"验证,然后"保存"
5. 点击顶栏"本地/网络"按钮切换到网络来源即可浏览播放

## 说明

ExoPlayer/Media3 最低需 API 16,虽可用于安卓 4.2.2,但为保证兼容性和稳定性,采用系统原生 MediaPlayer。
